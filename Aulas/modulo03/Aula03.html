Elementos de linha

Ocupam toda a largura disponível, exemplo: <a> <span> <strong> <em> <img>

Elementos de linha não devem conter elemenos de bloco

Categorias de conteúdo

Metadata content

São infomações de configurações do arquivo html

<tilr>: informa o título da página

<meta>: definir codificações

<link> e <style>: importara/anexar CSS

<script>: importar/anexar comandos javascript

Flow Content

Representa a maior parte dos elementos usados no body

<div>: criar uma divisão genérica, agrupar "pedaços" de codígo.

<p>: Criar paragrafo dentro da paágina.

<section>: Agrupa conteúdos que partilham do mesmo assunto/ideia.

<article>: conteúdo independente e ompleto por si só (faz sentido sozinho).

<img>: Importa imagens, desenhos, foto (não precisa de tag e fechamento).

<form>: Criar formúlarios, o usuário pode digitar dados e/ou mensagens, fazer login.

Sectioning Content

Organizar grander áreas do documento

<section>: Agrupa conteúdos que partilham do mesmo assunto/ideia.

<article>: conteúdo independente e ompleto por si só (faz sentido sozinho).

<aside>: Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia e ent).

<nav>: Agrupar links de navegação.

Heading Content

h1, h2, h3, h4, h5 e h6: Adicionar títulos e subtítulos

<hgroup>: Agrupar elementos de títulos, Exemplo:

Aprenda HTML
SENAI Americana

Phrasing Content

Elementos que marcam textos ou partes de textos.

<span>: Um bloco genérico, não uda nada sozinho, porém pode aplicar CSS ou chamar funções/comportamento com javascript

<a>: Criar um link para direcionar o usúario para outra página,utilizando o atribuo href. Exemplo: Clique aqui para acessar

<strong>: Serve para deixar uma parte do texto em negrito.

<em>: Serve para deixar uma parte do texto em itáloco.

<mark>: Serve para adicionar um marcador em uma parte do texto.

<img>: Importa imagens, desenhos, foto (não precisa de tag e fechamento).

Embedded Content

Utilizado para inserir um conteúdo externo

<img>: Importa imagens, desenhos, foto (não precisa de tag e fechamento).

<videi>: Adicionar imagem, desenho, foto (não precisa de tag de fechamento).

<canva>: Criar uma tela em branco que poderá ser usada pelo javascript

<svg>: Desenhar gráficos baseados em vetores

<iframe>: Colocar outra página inteira dentro do seu website (muito usado para adicionar mapas e vídeos)

Interacive Content

Permite interações com o usuário

<a>: Criar um link para direcionar o usúario para outra página,utilizando o atribuo href.

<button>: Criar botão. Exemplo:

<input>:Usado para receber dados do usuário. Dentre os dados aceios estão:

type="text": campo de texto curto; type="password": Oculta os caracteres digitados; type="email" ou "number": Valida dados especifícos; type="checkbox" ou "radio": Caixas de marcação e escolha única ***type é uma tag que não precisa de fechamento

<select>: Criar uma caixa de seleção em formato de linha suspensa(dropdown)

<textarea>: Criar uma caixa com várias linhas, serve para textos longos, comentários, mensagens e biografias
